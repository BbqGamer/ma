# Design Document: Curriculum Learning via Meta-Learning

This document outlines the mathematical framework for learning loss weights $w$ through a meta-learning outer loop with monotonic constraints.

## 1. Loss Formulation
The total loss function $L$ is a weighted sum of individual loss functions $L_{i}(\theta)$, representing a progression from crude to detailed approximations of the task:

$$L(w, \theta) = \sum_{i=1}^{N} w_{i} L_{i}(\theta)$$

**Key Components:**
* **$L_{1}$**: The crudest approximation of the learning task.
* **$L_{N}$**: The most detailed approximation.
* **$w$**: Loss weights $(w_{1}, \dots, w_{N})$ that must follow a curriculum schedule.

## 2. Weight Constraints and Softmax Bridge
To ensure the weights are non-negative and normalized ($\sum w_{i} = 1$), optimization is performed on an unconstrained parameter vector $u = [u_{1}, \dots, u_{N}]$. The actual weights are derived via a Softmax function:

$$w_{i}(u) = \frac{e^{u_{i}}}{\sum_{j=1}^{N} e^{u_{j}}}$$

### Curriculum Schedule Requirements
The weights are treated as meta-parameters that must follow specific monotonic trends:
* **Crude Losses ($L_{1}$):** The weight $w_{1}$ must monotonically decrease ($\Delta w_{1} \le 0$).
* **Detailed Losses ($L_{N}$):** The weight $w_{N}$ must monotonically increase ($\Delta w_{N} \ge 0$).

## 3. Optimization Loops

### Inner Loop (Model Update)
Model parameters $\theta$ are updated using standard gradient descent based on the total loss $L$ and current weights $w(u)$:

$$\theta'(u) = \theta - \eta_{\theta} \nabla_{\theta} L(w(u), \theta)$$

### Outer Loop (Meta-Update)
The unconstrained parameters $u$ are optimized using a meta-objective that balances validation performance with curriculum constraints:

$$L_{\text{meta-mono}}(u) = L_{\text{meta}}(u) + \lambda R_{\text{grad}}(u)$$

Where $L_{\text{meta}}(u)$ is the validation loss using the adapted parameters $\theta'(u)$:

$$L_{\text{meta}}(u) = L_{\text{val}}(\theta'(u))$$

## 4. Monotonic Gradient Regularization
The term $R_{\text{grad}}$ is designed to penalize the gradient of $u$ when it pushes the weights in a direction contrary to the curriculum schedule.

### Ideal Gradient Direction ($D$)
The desired change $\Delta w_{i}$ is defined by the direction vector $D$:
* **$D_{i} = -1$** for crude losses ($i \in [1, \dots, k]$).
* **$D_{i} = +1$** for detailed losses ($i \in [k+1, \dots, N]$).

### Regularizer Definition
Let $g_{i} = \nabla_{u_{i}} L_{\text{meta}}$ be the performance gradient. The regularization term is defined as:

$$R_{\text{grad}}(u) = \sum_{i=1}^{N} \max(0,\; g_{i} \cdot \text{SignCorrection}_{i})$$

**Sign Correction Logic:**
| Loss $L_{i}$ | Desired Trend $D_{i}$ | Opposing Update Condition | $\text{SignCorrection}_{i}$ |
| :--- | :--- | :--- | :--- |
| Crude ($i \le k$) | ↓ (negative) | $\Delta u > 0$ (i.e., $g < 0$) | $-1$ |
| Detailed ($i > k$) | ↑ (positive) | $\Delta u < 0$ (i.e., $g > 0$) | $+1$ |

## 5. Final Meta-Update
The unconstrained parameters are updated via gradient descent on the combined meta-objective:

$$u_{\text{new}} = u_{\text{old}} - \eta_{u} \nabla_{u} L_{\text{meta}} - \eta_{u} \lambda \nabla_{u} R_{\text{grad}}$$

This ensures the learned weights follow the curriculum while optimizing overall performance.
