- Prepare the data for training and experimentation
    - Gaussian Continuation
        - use the VLSE generator to create a dataset $(X, Y_{raw})$ of size $N$.
        -  select $K$ stages of smoothing defined by a decreasing sequence of sigmas: $\Sigma = [\sigma_{max}, \sigma_{max-1}, \dots, \sigma_{min}, 0]$. Set $\sigma_{max}$ roughly equal to the mean distance between nearest neighbors in $X$ (to ensure heavy blurring).
        - calculate the pairwise distance matrix $D_{dist}$ for input $X$ (shape $N \times N$). Use k-nearest neighbors approximation (`sklearn.neighbors.NearestNeighbors`) or approximate nearest neighbors (https://github.com/spotify/annoy)
        - For each $\sigma_k$ in $\Sigma$
            - compute the Gaussian Kernel matrix $W_k = \exp(-D_{dist}^2 / (2\sigma_k^2))$
            - normalize rows: $W_k' = W_k / \text{row\_sum}(W_k)$.
            - compute smoothed targets: $Y_{\sigma_k} = W_k' \times Y_{raw}$.
            - store dataset $D_k = (X, Y_{\sigma_k})$.
